# **App Name**: VoyageWise CRM

## Core Features:

- Client Management: Store and manage customer profiles, including contact information, preferences, and travel history.
- Itinerary Builder: Create customized travel itineraries with flights, hotels, and activities. Let LLM tool suggest places to go based on users prompts
- Lead Management: Track and manage new leads through the sales pipeline, from initial contact to conversion.
- Booking Management: Manage all booking details, including flights, hotels, and other travel arrangements.
- Invoicing and Payments: Generate invoices and track payments for travel bookings.
- Process Tracking: Monitor the progress of each booking through a series of steps, marking completed stages.
- Role-Based Access: Implement role-based access control for employees, admins, and management to ensure data security and compliance.
- Customer Logs Management: To record each activity for each customer.
- Follow-up Marked: Marked the Follow-up done for each costumer
- Customer Status: Define and track the status of each customer (e.g., active, inactive, lead, prospect).
- Report Section: Analyze performance metrics and generate reports on key business activities.
- Hotel Booking Vouchers: Generate a real Word (.docx) confirmation voucher, formatted to match the agency's reference layout, directly from a booking's Guest/Room/Stay details — available for hotel bookings only.
- Itinerary "Other Format" Export: A second, freeform itinerary layout (separate from the structured flight/hotel/activity builder) that can be filled in by hand or auto-filled by pasting a raw itinerary and extracting it with AI (NVIDIA NIM by default, Google Gemini as an alternate provider), then exported as a polished .docx; in-progress work is kept in the browser's local storage so it survives navigation without re-spending AI calls.

## Style Guidelines:

- Primary color: Light sky blue (#87CEEB) for a sense of tranquility and openness.
- Secondary color: Pale blue (#ADD8E6) for a calm and clean backdrop.
- Accent color: Cloud white (#F0F8FF) to highlight important actions and information.
- Body and headline font: 'Open Sans', a humanist sans-serif that combines a modern look with warmth.
- Use clear and intuitive icons to represent different features and actions, in the style of simple line drawings.
- Design a clean and organized dashboard layout for easy access to key information and tools.
- Implement subtle animations for transitions and interactions to enhance the user experience.
